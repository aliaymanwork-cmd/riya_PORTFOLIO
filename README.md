# Ria Fathima Portfolio

A responsive editorial-style digital marketing portfolio built from the uploaded portfolio video as visual inspiration.

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Customize
- Edit all text/content in `index.html`.
- Replace images inside `assets/`.
- Replace `assets/portfolio-reel.mp4` with the final reel/video.
- Change colors and typography in `css/style.css`.
- Update email, Instagram, LinkedIn and WhatsApp links in `index.html`.

## Deploy
Upload the folder to Netlify, Vercel, GitHub Pages, Hostinger, or any static hosting provider.

## Notes
The supplied video is included as a local portfolio/reel asset. Replace it if it contains reference/demo material rather than the final portfolio owner's content.
